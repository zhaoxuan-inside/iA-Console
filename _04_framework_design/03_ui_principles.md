# 03 UI 设计原则（_04_framework_design）

> 状态：draft　更新：2026-10-11

定位：TUI 的美观上限由排版纪律决定，不由装饰决定。对标 **iA Writer 的排版哲学**——内容即界面，克制、留白、无噪音。

## 1. 设计原则

| 原则 | 落地方式 |
|---|---|
| 内容即界面 | 默认无框线/极弱框线（单线或空格分隔），禁用双重边框、阴影块等重型装饰；标题用字重与间距表达，不用大色块 |
| 留白 | 8/4/2/1 间距令牌（空行/双空格/单空格），段落间至少一个空行；列表密度可调（舒适/紧凑） |
| 焦点模式 | 当前输入行与活动提案高亮，历史内容降为 40% 灰阶；类似 iA Writer 的"只照亮正在写的句子" |
| 克制用色 | 语义色只给信息：风险等级（safe 绿/caution 黄/dangerous 橙/destructive 红）、diff 增删、错误码；其余一律前景/前景淡化两级 |
| 等宽排版纪律 | 所有对齐按字符网格计算；中文按 2 格宽处理（CJK width），混排不破版 |

## 2. 主题系统

| 项 | 方案 |
|---|---|
| 模式 | `ui.theme = day \| night \| auto`；auto 查询终端背景色（OSC 11）自动切换 |
| 色板 | 每主题 10 个语义令牌：bg/fg/fg-dim/accent/safe/caution/dangerous/destructive/diff-add/diff-del；真彩优先，256 色/16 色自动降级（AC-28） |
| 令牌化 | 组件禁止写死颜色，一律引用令牌；主题即令牌表（TOML 可自定义覆盖） |

## 3. 字体策略

TUI 字体由终端模拟器决定，本项目不分发字体（_01 非目标），提供三件事：

1. **字体选型建议**（文档）：iA Writer Mono / JetBrains Mono / Maple Mono / 更纱黑体 Term 等宽中文字体；
2. **渲染友好设计**：排版令牌按等宽字体度量设计，CJK 混排 2 格宽处理；
3. **Nerd Font 渐进增强**：检测到 Nerd Font 时启用图标字形，否则退化为 Unicode/ASCII 符号（`⚠`/`!`、`✓`/`v`）。

## 4. 标记语言与界面动线（详见 _06 external 第 6 节）

- 输入框是唯一入口：`??` 唤起 AI、`/` 管理命令、`---` 任务分隔、`#` 备注、`\` 转义。
- 界面分区：单列主轴（输入行 → 当前任务流 → 淡化的历史），侧栏仅按需浮出（/config 面板），不做常驻多栏。
