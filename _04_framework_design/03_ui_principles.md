# 03 UI 设计语言：iA Writer 式（_04_framework_design）

> 状态：draft　更新：2026-10-11

本文件是 iA-console 全部前端（TUI、CLI 输出格式）的**唯一设计语言依据**。对标 iA Writer 的设计语言——不是"参考其风格"，而是把它的设计词汇逐一翻译到终端约束之下。

## 0. 设计哲学（源自 iA Writer）

1. **内容即界面**：屏幕上每个非内容元素（框线、图标、徽标、状态栏）必须为自己辩护，辩不过就删除。
2. **减法至上**：先加齐功能，再删到"再删就坏"为止；宁可留白，不可堆砌。
3. **层级只靠三件事**：字重、灰阶、留白。不用全框线、不用色块背景、不堆图标。
4. **一支笔原则**：全界面只有一个强调色（accent），只给当前焦点；其余信息一律灰阶。
5. **同一把尺子**：所有间距、缩进、对齐来自同一套节奏令牌，禁止随手值。

## 1. iA Writer 概念 → iA-console 翻译表

| iA Writer 的做法 | iA-console 的对应 | 约束下的取舍 |
|---|---|---|
| 编辑区即一切，无工具栏 | 主轴 = 输入行 + 任务流，无常驻侧栏 | 管理面板（/config 等）按需浮出，用毕即收 |
| Focus Mode（只照亮当前句） | 活动提案与当前输入行全亮，其余内容分三档灰阶淡出 | 淡出档位：fg-40（上一任务）/ fg-25（更早历史） |
| Markdown 语法字符弱化 | 命令行内语法分层：命令名最亮、flag 次之、值与路径再次、引号符号最淡 | "解释文字"才是内容主角，与 iA Writer 同构 |
| 引用块左侧竖线 | 提案卡 = 左侧 accent 色条（2 cell），**无外框** | 全项目禁用双线框与整框；分隔靠空行 |
| 极简、按需出现的工具 | 输入标记（`??` `/` `---` `#`）替代一切常驻按钮 | 手不离键盘，视线不迁移 |
| 一支 accent 笔 | accent 只标当前焦点行/活动卡色条 | 一屏最多一处 accent |
| Duo/Mono/Quattro 字体角色 | 终端字体不可控 → 字体角色由**字重 + 灰阶**承担 | 字号不可变（终端决定），如实接受 |

## 2. 色彩系统

**灰阶 5 档 + accent 1 + 语义 6**，共 12 个令牌，两主题各一张表：

| 令牌 | day（纸） | night（墨） | 用途 |
|---|---|---|---|
| bg | #FAFAF7 | #1B1D22 | 纸面（day 偏暖白，night 偏蓝黑，均非纯色） |
| fg | #262A33 | #D6D8DD | 正文 |
| fg-60 | #6B7080 | #8B8F98 | 次要文字（解释、参数说明） |
| fg-40 | #9CA1AC | #5C6068 | 上一任务/次次要 |
| fg-25 | #C3C7CE | #3A3E46 | 历史/装饰符号/行号 |
| accent | #316BFF | #6E9BFF | **唯一强调色**：焦点行、活动卡色条 |
| safe | #2E7D32 | #66BB6A | 风险=安全 |
| caution | #B26A00 | #FFB74D | 风险=留意 |
| dangerous | #C7500A | #FF8A50 | 风险=高危 |
| destructive | #B3261E | #FF5C52 | 风险=破坏性 |
| diff-add | #2E7D32 | #66BB6A | diff 增 |
| diff-del | #B3261E | #FF5C52 | diff 删 |

规则：① 一屏最多一处 accent；② 语义色只出现在风险、diff、错误三类信息；③ 256 色终端降级到最近色板，16 色再降一级，布局永不因降级破坏；④ `ui.theme = day|night|auto`（auto 经 OSC 11 探测终端背景）。

## 3. 排版与节奏

- **间距尺**：1 / 2 / 4 / 8 cell 四档；段落之间 = 1 空行；卡片之间 = 2 空行。禁止半格与随手空格。
- **命令行语法分层着色**（提案与执行回显统一）：

```text
fg      命令名           find
fg      子命令           compose
fg-60   长参数/值         --type f  -mtime -7
fg-40   路径             /var/log
fg-25   引号与管道符      |  "  '
```

- **层级**：bold 表"当前/活动"，正常表"内容"，fg-60/40/25 表"从属到历史"。字号与斜体不可依赖（终端字体各异）。
- **CJK**：按 2 cell 宽对齐，混排表格断言不破版（组件单测覆盖）。

## 4. 组件规范（无框化）

### 提案卡（核心组件，两态）

**摘要态（默认，所有来源）**——命令 + 一句话 + 风险，解释收起：

```text
  ▍ find /var/log -type f -mtime -7 | sort -rn | head -10
  ▍
    找出最近 7 天修改过的 10 个最大文件 · 风险：安全
    [执行] [解释 e] [取消]
```

**详解态（`e` 键展开 / `--explain`）**——逐参数白话 + 影响面：

```text
  ▍ find /var/log -type f -mtime -7 | sort -rn | head -10
  ▍
    按修改时间找出 /var/log 下最近 7 天的 10 个最大文件。

    -type f    只看普通文件
    -mtime -7  最近 7 天内修改过
    sort -rn   按大小倒序
    head -10   取前 10 行

    影响：只读操作，不修改任何文件
    风险：安全                                [执行] [取消]
```

- `▍` = 左侧 accent 色条（活动提案）；非活动提案色条为 fg-25；**无外框、无底色块**。
- 命令行 bold；参数解释表空格对齐（`fg-25` 参数名 + `fg-60` 解释）；风险值语义色；操作键为文本方括号样式，焦点项 bold 反白。
- **解释默认收起（AC-01/35）**：`e` 键双向切换；AI 提案（ask）与直接输入同规则——解释是按需服务，不是默认包装。

### 直通行（用户确定命令，无卡、无拦截）

用户直接输入：**无解释包装、无强确认**，回车即执行；风险一律**弱提醒**渲染（AC-04）：

```text
$ rm -rf ./build/          ← dangerous/destructive：命令红字 + 行尾 ⚠ + 视口边缘 1 cell 红描边
（回车直接执行，不做强确认）
```

### 翻译行（显示转换逻辑，AC-36）

```text
~~ls~~ → Get-ChildItem                                    非高危：回车直接执行
~~rm -rf build~~ → Remove-Item -Recurse -Force build   ⚠   确认 y / 取消 n   高危：需确认
```

- 原命令删除线（ANSI SGR 9），终端不支持时降级为 `fg-25` 灰阶 + `→` 箭头表达转换。
- 译文按命令行语法分层着色；差异说明 `e` 展开收起不变。

### 弱提醒三件套（dangerous/destructive 激活，执行后消退）

1. **命令文字变红**（语义红 destructive，dangerous 用橙）；
2. **行尾 ⚠ 告警标识**（Nerd Font 升级字形，Unicode 回退）；
3. **视口边缘 1 cell 红描边**——与无框设计不冲突：描边是瞬时环境状态（ambient），非常驻装饰。

配置 `risk.confirm_mode = weak|ask`（默认 weak 即本节语义；ask 恢复强确认，供谨慎用户）；**翻译高危与 Agent 路径恒走确认，不受此开关影响**。

### 列表（history / 回滚点 / 文件版本 / 方案库）

- 无斑马纹、无表头色块；seq/行号 `fg-25`，时间 `fg-40`，命令正文 `fg`，状态符号用语义色（✔ ◐ ✘ 等 Unicode 字符，Nerd Font 检测到则升级字形）。
- 列表行高 1 行，组间 1 空行；`---` 任务分隔线渲染为居中 `fg-25` 的 `· · ·`，弱化存在感。

### 对话流（AI 面板）

- 用户输入行：accent 光标行；`??`/`/` 标记字符 `fg-25` 弱化（同 iA Writer 弱化语法字符）。
- AI 回答：无前缀正文 `fg`；回答中的命令块按"命令行语法分层"着色，底部 `fg-40` 一行操作提示（[转为提案]）。
- 思考中：单行 fg-25 的呼吸点（静态帧交替，无动画帧率追求）。

### 错误与诊断

- 错误 = 行内红字（destructive）+ 错误码 `fg-40` + 一行指引，不弹窗、不遮罩。
- 诊断报告 = 提案卡变体：根因正文 `fg`，stderr 证据行 `fg-60` 加 `│` 前缀，置信度 `fg-40` 尾注。

## 5. 动效与反馈

- **无动画**：状态变化 = 内容替换；唯一动态是思考指示（两帧交替）。
- 进度 = 单行文本（百分比/已处理计数），完成后该行归档为普通历史行。
- 一切反馈就地发生（输入行上方插入内容），绝不滚动跳跃用户正在看的行。

## 6. 字体策略（终端侧建议，不分发）

- 推荐清单：iA Writer Mono SBF / JetBrains Mono / Maple Mono / 更纱黑体 Term SC（中文等宽）。
- 设计按"任意等宽字体 + CJK 双宽"度量，不假设连字（liature）关闭与否均不破版。
- Nerd Font 渐进增强：探测到则状态符号升级字形，否则 Unicode 回退；**图标永远可选**。

## 7. CLI 输出同语言

`iac` 非 TUI 模式的 stdout 遵循同一语言：无框表格（空格对齐）、同色令牌（非 TTY 自动去色）、错误 = 单行红字 + 错误码。`--json` 输出零着色。
