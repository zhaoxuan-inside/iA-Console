# 品味宪章（DESIGN.md）——iA-console 重建基线

- **状态**：`CONFIRMED`（2026-10-24 重建实现落地后建档；令牌与实现同源，`iac-gui/src/theme.rs` 为唯一事实源）
- **设计语言**：iA-Writer 式——内容即界面、留白、克制、无框线或弱分隔

## 1. 原则

1. **内容即界面**：无装饰性控件，语义信息（风险色、accent 条、等宽文本）承担全部视觉层级。
2. **终端优先**：管理功能全部在终端面内以 TUI 风格渲染（等宽、无框），GUI 只做窗口外壳与鼠标支持（域 18，Q38）；不做原生控件设置页。
3. **无框化条目**：任务流条目无边框，用留白与缩进分组；分隔线仅用于任务段（`---`）。
4. **风险即颜色**：safe/caution 用前景层级区分，dangerous/destructive 走 Destructive 令牌 + ⚠ 标记；弱提醒不拦截（Q34）。
5. **主题克制**：day/night/auto 三态，auto 跟随系统；14 令牌覆盖全部语义，禁止临时取色。

## 2. 十四令牌（与 `theme.rs` 同源）

| 令牌 | 语义 | 使用位置 |
|---|---|---|
| Fg | 正文 | 任务流/终端前景 |
| Fg25 | 弱化文本 | 提示符回显、注入上下文透明区、辅助提示 |
| Fg60 | 次级文本 | 翻译行原命令灰阶、备注 |
| FgBold | 强调正文 | 活动提案命令 |
| Accent | 品牌强调 | 活动提案 accent 条、光标 |
| Destructive | 危险 | dangerous/destructive 命令、武装态警告 |
| OkBg/OkFg | 成功 | 执行成功态 |
| WarnBg/WarnFg | 警示 | 弱提醒背景层 |
| SynKeyword/SynString/SynComment/SynNumber | 语法令牌 | 结构化渲染（域 17，console/TUI 高亮） |

## 3. 布局（域 18 重建落定）

- **每窗口**：标签栏（顶部）→ 任务条区（可折叠，TUI 风格条目：提案卡/管理输出/AI 回答）→ 真终端（主体）→ 主输入行（钉底）。
- **每标签**：独立 PTY 会话 + 独立任务流 + 独立会话绑定（Q39/Q46）。
- **侧栏（辅助）**：对话轨视图（Ctrl+B），不作为 AI 唯一入口（Q7）。
- **提案卡**：命令行 + 风险着色 + 一句话摘要（`e` 展开逐参数解释与注入上下文，Q16/Q20）；多候选 `↑↓` 切换（Q17）。

## 4. 字体

- 等宽优先（终端面全部等宽）；CJK 运行时注入系统 Noto/WQY 系字体（不分发字体，G13 非目标约束延续）。
