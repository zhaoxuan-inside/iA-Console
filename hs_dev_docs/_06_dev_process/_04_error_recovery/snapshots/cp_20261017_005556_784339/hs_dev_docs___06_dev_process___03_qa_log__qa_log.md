### Q7. 「AI 驱动命令」核心思想的主交互形态（头号验收主题①）

- **题域**：产品语义 / 核心交互形态
- **题干**：v0.1.0「功能没有实现 AI 驱动命令的核心思想」——定型其主交互形态；并请补充旧版落差场景（想做什么 → 实际发生 → 期望发生）。
- **选项（3）与利弊**：
  - A：主输入行直驱（推荐）——自然语言直接在主输入行输入（或 `??`），AI 就地生成命令提案、确认即执行；侧栏退为辅助（对话/解释/历史）。心流不断；代价：需设计「命令 vs 自然语言」输入分流。
  - B：侧栏伴随助手——终端为主体、AI 交互固定侧栏（旧版形态）。职责清晰；代价：注意力两处跳转、AI 不参与主输入。
  - C：对话流主界面——会话/任务流为主视图、终端退为可展开执行面板。AI 连续性最强；代价：改变 Console 形态与终端习惯。
- **开发者答复**：A —— 主输入行直驱
- **采纳决策**：CONFIRMED——「AI 驱动命令」主交互形态 = **主输入行直驱**：主输入行是 AI 驱动的必经路径；侧栏保留为辅助视图，不作为 AI 唯一入口。旧版具体落差场景未另附文字取证（保留为后续场景走查补充项）；输入分流、提案呈现/确认方式、执行流转等细则在能力域场景走查（域 1/4/18）逐项钉细。
- **关联落盘**：PRD 骨架 §1（主题①形态）；本日志。

### Q8. 开箱体验（FTUE）默认路径

- **题域**：开箱体验 / AI 能力到手路径
- **题干**：新用户（新机器、零配置、无 API Key）首次打开前 30 秒期望什么；三方案比选。
- **选项（3）与利弊**：
  - A：轻引导不挡路（推荐）——直进主界面；AI 未配置时一次性配置卡（一键本地模型 / 云 Key / 稍后）；未配置期间基础能力完整可用。
  - B：首启配置向导——分步配置后进主界面；首次进入被「挡在门外」。
  - C：发行包捆绑本地模型——真·开箱即用；安装包体积大涨、分发升级成本高。
- **开发者答复**：A —— 轻引导不挡路
- **采纳决策**：CONFIRMED——首次启动直进主界面；AI 未配置时以一次性配置卡引导「一键下载本地模型（免 Key）/ 填云 API Key / 稍后再说」；未配置期间直接命令、翻译、历史、方案库等基础能力完整可用。默认本地模型候选、下载/校验体验细则归域 12（内置本地模型）走查。
- **关联落盘**：PRD 骨架 §3；域 12 走查输入。
