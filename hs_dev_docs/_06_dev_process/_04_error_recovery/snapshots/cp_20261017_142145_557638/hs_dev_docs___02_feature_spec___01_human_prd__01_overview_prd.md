## 1. 产品愿景与头号验收主题

- **一句话定位（候选）**：天下没有难用的 Console——把自然语言意图变成可信、可解释、可审计的命令执行闭环，并以同一套能力对 Agent 原生开放。
  - 来源：`DERIVED`（旧定位「伴生智能内核」，见旧 `_01_business/01_requirements.md`）；待开发者确认保留/修正。
- **头号验收主题（`CONFIRMED`，Q2）**：
  1. 「AI 驱动命令」核心思想必须在主交互中真实兑现（第 2 轮 Q7 定型具体形态）；
  2. UI/交互质量有可验收的标准清单（第 2 轮 Q9 取证）。
- **主交互形态（`CONFIRMED`，Q7）**：主输入行直驱——自然语言直接在提示符输入（或 `??`），AI 就地生成命令提案、确认即执行；侧栏保留为辅助视图（对话/解释/历史），不作为 AI 唯一入口。交互细则（输入分流、提案呈现/确认、执行流转）待域 1/4/18 场景走查钉细。
- **开箱路径（`CONFIRMED`，Q8）**：轻引导不挡路——首次启动直进主界面；AI 未配置时一次性配置卡（一键本地模型 / 云 API Key / 稍后）；未配置期间基础能力（直接命令/翻译/历史/方案库）完整可用。
- **单一核心假设（`CONFIRMED`，Q13）**：主输入行 AI 直驱闭环——自然语言 → 可信提案（命令+逐参数解释+风险）→ 确认执行 → 留痕。其余能力域按「支撑核心闭环 / 延伸价值」排优先级。
- **范围收口（`CONFIRMED`，Q14）**：全量 18 能力域，无裁剪、无未验证降级；仅排实施顺序（核心闭环优先）。
- **核心闭环主成功流（`CONFIRMED`，Q15~Q17）**：混合识别分流（自然语言自动走 AI；命令形态直接执行；`??` 强制 AI、`\` 强制字面）→ 提案就地展开（命令+一句话摘要+风险；逐参数解释默认收起 `e` 展开）→ Enter 确认执行 / Esc 取消 / 可编辑 → 多候选 2~3 个上下键切换（默认平台惯例最优）。
- **核心闭环异常路径与上下文（`CONFIRMED`，Q18~Q22）**：误判纠正 = 执行后失败兜底（command not found/非零退出就地提示「要不要 AI 帮忙？」一键转提案，Q18）；AI 运行期失效 = 就地显示具体原因（未配置/超时/中断）+ 一键重试 + Esc 清除，直接命令不受影响（Q19）；上下文注入 = cwd + 平台/Shell + 最近 10 条历史，注入内容 `e` 展开区透明可查，终端输出仅失败诊断附带（Q20）；高危提案默认展开逐参数解释 + 确认升级二次 Enter/确认词（Q21）；生成期锁定输入行杜绝竞态，Esc 可取消，解锁自动，占位替换高度突变受控（Q22）。
- **域 1 候选排序（`CONFIRMED`，Q23）**：平台惯例 > 低风险 > 历史使用频率；超 3 截断为前 3 + 「可追问细化」提示。**域 1 需求面关闭**（展开区最大高度随原型走查由 frontend 专项钉，不阻塞需求面）。
- **域 13 输入标记语言（`CONFIRMED`，Q24~Q30）**：废弃 `/` 特殊前缀——系统管理功能 = **内置命令**，统一 `ia-` 命名空间（`ia-config`/`ia-help`/`ia-model` 等；与外部命令同一 Q15 分流；`ia-` 零撞名，「内置优先于 PATH」退为兜底保险；名单随能力域走查登记、`ia-help` 列全部）；`---` 任务段 = AI 注入历史窗口不跨越最近分界（cwd/平台始终注入；完整历史保留可检索；正式生效）；`#` 保持 shell 注释本义——会话备注**保留**并并入域 4 对话轨（随上下文注入，可「钉住」跨 `---`）；`??` 强制 AI 保留、**特权仅限行首**（参数位置保持通配本义）；`\` 强制字面维持（与转义本义同向）。**域 13 需求面全部收口**。
- **域 4 同屏 AI 对话（`CONFIRMED`，Q31~Q33）**：提问 vs 意图 = 同一输入行**智能区分**——AI 判定求解释 → **就地展开解释卡**（不占提案确认流，Esc 收起；与提案卡视觉区分随原型钉）；判定要做事 → 域 1 提案流；误判就地一键切换；侧栏保留为对话续聊与历史场所。解释卡/对话回答中的命令块提供「转提案」快捷键/按钮——**一键落入主输入行提案展开区**，复用 Q16 确认流与 Q21 高危闸门，留痕走域 7。对话轨上下文 = **Q20 基底 + 当前 `---` 段内对话轨内容**；`---` 对对话轨同样截断；钉住备注跨段注入、可查可取消。**域 4 需求面关闭**（余呈现细则随原型走查）。
- **域 8 风险闸门（`CONFIRMED`，Q34~Q37）**：维持 `safe/caution/dangerous/destructive` 四级；**静态规则库为主判定**（离线可用），AI 自评为辅、**冲突取更高等级**。四级语义边界：safe=只读/无副作用；caution=可逆副作用/局部影响；dangerous=可控数据丢失/系统状态破坏；destructive=大规模不可逆/系统级灾难。caution 及以下普通呈现，dangerous 起触发闸门。闸门矩阵：**人类直输** → 弱提醒不拦截（呈现随原型钉）；**AI 提案/翻译路径** → 默认展开逐参数解释 + 确认升级——分级：dangerous 二次 Enter（武装态显示警告摘要）、destructive 输入确认词；**Agent 路径** → 未带确认标志 → 拒绝执行并返回影响面说明、要求带确认重试（闸门与人一致）。直输/方案库条目默认不铺开解释，仅显式请求出现。**域 8 需求面关闭**。
- **域 18 GUI 主形态（`CONFIRMED`，Q38~Q42）**：管理功能全部在**终端面内渲染**（TUI 风格界面）；GUI = 窗口外壳 + 鼠标支持，不做原生控件设置页；双形态同一套实现、行为绝对一致（Q4 约束落地）。**多窗口自由模型 × 窗口内标签页**：可开多个独立应用窗口，每窗口可含多标签，每标签 = 独立终端会话（各自 cwd/env/历史段），共享同一 daemon 与数据库；**启动恢复上次全部窗口及其标签布局与各会话状态**（域 6 联动）。多客户端并存：GUI/CLI/TUI/MCP 同连一 daemon、各自独立会话、历史/审计统一入库跨端可检索；**GUI 启动自动拉起 daemon**、CLI/TUI 连接失败明确报错给启动命令；`ia-daemon` 内置命令管理生命周期。**域 18 需求面关闭**（呈现细则随原型走查）。
- **域 9 Agent 原生接口（`CONFIRMED`，Q43）**：**MCP + `iac --json` 双通道**——daemon 内置 MCP 服务（外部 Agent 标准接入）；`iac --json` 承载脚本/简单自动化；两通道经同一 dispatch 进入同一编排，闸门（Q35 确认标志）、记录、审计行为一致。待钉：MCP 能力面与权限边界（Q44）。
