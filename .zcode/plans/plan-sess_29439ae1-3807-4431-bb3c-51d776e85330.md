# UI 现代化改造（v0.2.6 → v0.3.0）

## Context

你令：从 GitHub 近两年开源 console/terminal 项目提炼设计语言，对本项目 UI 现代化。摸底结论决定了改造路线：

- **真 GUI 前端是 `iac-gui`（egui 0.31）**，`iac` 是 ratatui TUI 旁支（形态纠偏方向=独立 GUI）。
- **令牌层已经是 2024-2026 的**：iac-gui/theme.rs 就是按 Linear 官方规范值实现的（canvas #010102、四级 surface 阶梯、hairline #23252a、薰衣草 #5e6ad2/#828fff），仓库 design/refs/ 已存有 Linear/Warp/Raycast 三份设计语言规范文档。
- **组件层停在旧世代**：块条纯只读（无 hover 动作/cwd/运行指示）、提案卡键位画了没接线（**假象功能苗头，必须本轮去假象化**）、无命令面板、无状态栏、标签栏裸文本、任务区无语法高亮、TUI 的 ⚠ 弱提醒未移植到 GUI、两前端令牌同源异值。

## 设计语言定调（均为近两年，合规边界：不搬 Warp 代码）

| 参照 | 借什么 | 依据 |
|---|---|---|

## 改造清单（9 项）

1. **theme.rs 排版分工**（iac-gui/src/theme.rs）：解除「一切 monospace」——chrome（标签栏/侧栏/状态栏/pill/提示）改比例字体 12.5-13px，命令/终端/代码保持 mono，空态用 Heading 17；新增组件助手 `status_dot` / `kbd_chip`；token 色值不动（已是规范值）。
2. **块条交互化**（app.rs `draw_blocks`/`shell_block_row`）：每块 hover 出动作条（复制命令 / 插入输入行 / 重跑），`Sense::hover` + hover 高亮 Fg60→Fg；块行右侧 caption 短 cwd（tooltip 全路径）+ 耗时；运行中块用 `egui::Spinner` 替代「… 运行中」；点击块=插入命令到输入行（不执行）。
3. **提案卡去假象接线**（app.rs）：↑↓ 切活动候选、`e` 展开/收起（激活 `expanded` 死字段，删 `Tab.expanded` 死字段）、Esc 取消、Enter 执行活动候选——走既有 `iac_execute` 路径并带 `candidate_index`（协议已支持，core/src/executor/mod.rs:34），闸门语义不变（confirmed/confirm_word 照旧）。
4. **命令面板（新）**：Ctrl+K 开关；居中浮层 SurfaceRaised + hairline + radius 10（维持无阴影立场）；过滤框 + 动作列表（新标签/关闭标签/切换主题/对话轨开关/块条开关/清空块条/聚焦输入行）+ kbd 提示列；↑↓/Enter/Esc。顺带成为键位的可发现入口。
5. **状态栏（新）**：最底一行 caption 高度条：左 = daemon pill（启动即发 `iac_ping` 探测 + 周期复测，core/src/server/dispatch.rs:77，真实状态：已连接 Safe 点 / 失败 Dangerous 点 / 未探测 Fg40）+ cwd pill（点击复制路径）+ shell 名；右 = 主题模式 / 版本 / Ctrl+K 提示。
6. **标签栏升级**：裸 selectable_label → tab chip（选中=SurfaceRaised+hairline，Linear pill-tab 模式）；busy 标签加 accent 圆点；hover 显 × 关闭（实现时验证 backend drop 的 PTY 清理语义，不安全则先写 `exit` 再关）；Ctrl+T 新标签、Ctrl+W 关闭。
7. **输入行升级**：accent `❯` 前缀；移植 ⚠ 弱提醒——用 `iac_core::risk::assess_static`（iac/src/console.rs:753 同款语义：dangerous/destructive → 输入文本变 Destructive 色 + ⚠ 尾标，仅视觉不拦截；`??` 问 AI 路径不预警）。
8. **任务条区排版**（`draw_task_strip`）：代码/JSON 文本复用 `iac_core` 高亮（TUI 同款 token 映射）；busy 两帧 ASCII 点 → `egui::Spinner`；[问 AI]/[重试] 按钮统一 SurfaceRaised+hairline 样式；空态用 Heading。
9. **TUI 令牌对齐**（iac/src/theme.rs）：14 色值对齐 GUI（Day accent `#316BFF`→`#5e6ad2`、bg 对齐 `#fbfbfc` 等，纯值替换），同步 theme 7 个测试断言；TUI 交互一律不动。

版本：根 Cargo.toml workspace.version **0.2.6 → 0.3.0**。
